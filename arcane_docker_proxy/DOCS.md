# Read-only proxy

Install alongside the Arcane monitoring agent. Disable Protection mode for this proxy, then start it before the agent. Keep the agent protected.

`SP_ALLOWFROM` must contain the agent's internal hostname, generated by `tools/configure_repository.py` before publication. The default permits only localhost and is intentionally unusable by the agent. The proxy listens on the internal add-on network; no host ports are mapped.

The GET and HEAD endpoint allowlists are fixed in `config.json`. No POST, PUT, PATCH, DELETE, CONNECT or other methods are enabled. No per-container label overrides are enabled. File archives and image exports are excluded even though they use GET. Do not broaden the policy merely to remove Arcane UI errors.

Docker socket access requires running the proxy as root inside its container. A read-only socket mount alone cannot prevent Docker changes; the HTTP method/path filter enforces this policy. A compromised proxy process would still have host Docker access. Container metadata and logs may disclose secrets.
